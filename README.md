# 奈良教育大学 空き教室・利用状況チェッカー 🏫

シラバス時間割データ（`syllabus_all_semesters.csv`）をもとに、前期・後期の**「空き教室」および「使用中の教室・講義」**をリアルタイムに検索・確認できるWebアプリケーションです。

---

## 🌟 主な機能

1. **🔍 空き教室を探す（メイン機能）**
   - **学期（前期／後期）**、**曜日（月〜金）**、**時限（1・2限〜9・10限）**を指定して、現在利用可能な空き教室をカード形式で一覧表示。
   - 教室カードには、その日の**全時限の利用状況（終日空きか、何限から授業があるか）**もミニタイムラインで表示。
   - **「使用中の教室も表示」スイッチ**：オンにすると、そのコマで何の授業がどの教員により開講されているかも一目で分かります。

2. **⚡ 今すぐ使える教室（ワンタップジャンプ）**
   - 現在の曜日・時刻を自動判定し、今すぐ自習や作業・サークル等で駆け込める空き教室へ即座に移動します。

3. **📅 教室別タイムテーブル**
   - 教室（例: `101教室`、`大講義室`など全90室）を選ぶと、月曜〜金曜の1週間の時間割カレンダーを表示。
   - 空いているコマ（緑色）と授業が入っているコマ（青色）が直感的に分かります。
   - 授業をクリックすると、担当教員や単位数、シラバスの成績評価方法などの詳細がポップアップします。

4. **📊 全体稼働マトリクス**
   - 横軸に曜日×時限（計25コマ）、縦軸に教室を並べた一覧表。大学全体の空き具合・稼働率を鳥瞰できます。

5. **📖 講義一覧・検索**
   - 科目名、教員名、教室名でのインクリメンタル検索に対応。

---

## 💻 すぐに使う方法（ローカル環境）

このフォルダ内の **`index.html`** をダブルクリックしてブラウザ（Google Chrome, Edge, Safariなど）で開くだけです！
外部サーバーやNode.jsなどは一切不要で、完全オフラインでも高速に動作します。

---

## 🌐 ネット上で見られるようにする方法（完全無料）

以下のいずれかの方法で、**数分でインターネット上に公開**し、スマートフォンや他のPCからいつでも見られるようになります。

### 【方法1】Netlify Drop（おすすめ・一番簡単！）
1. ブラウザで [Netlify Drop](https://app.netlify.com/drop) を開きます。
2. この `classroom-finder` フォルダを画面にそのまま**ドラッグ＆ドロップ**します。
3. わずか数秒で全世界公開用のURL（例: `https://xxxx.netlify.app`）が発行されます。

### 【方法2】GitHub Pages（安定的・学内共有向け）
1. [GitHub](https://github.com) で新規リポジトリ（Public）を作成します（例: `nara-edu-rooms`）。
2. このフォルダのファイルをアップロードします：
   - `index.html`
   - `style.css`
   - `app.js`
   - `data.js`
3. リポジトリの **Settings** → **Pages** を開き、**Branch: main** を選択して **Save** を押します。
4. 数分で `https://<あなたのGitHubユーザー名>.github.io/nara-edu-rooms/` で公開されます。

### 【方法3】Cloudflare Pages / Vercel
- GitHubリポジトリを接続し、フレームワークプリセット「None / Static HTML」でデプロイすれば即時公開可能です。
